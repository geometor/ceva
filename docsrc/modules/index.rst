Modules
=======

The ``geometor.ceva`` Python package provides 100% exact symbolic ``SymPy`` and ``geometor.model`` constructions, static-barycentric solvers, isotomic & harmonic ``@proposition`` proofs, Rational Trigonometry spread verifiers, odd-polygon and circumscribed-conic analyzers, and 3D tetrahedral equilibrium solvers for Giovanni Ceva's *De lineis rectis se invicem secantibus statica constructio* (Milan, 1678).

CLI Summary
-----------

.. code-block:: bash

   /home/phi/PROJECTS/geometor/.venv/bin/python -m geometor.ceva

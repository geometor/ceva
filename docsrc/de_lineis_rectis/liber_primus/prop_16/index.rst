Proposition XVI: Base Ratio in Element III
==========================================

.. folio:: 0040
   :page: p. 23

**Proposition XVI · Theorem VII** (p. 23, `Tab. 2, Fig. 17`)

*In Element III, the ratio of the base segment :g:`BC` to the entire base :g:`CA` equals the corresponding pyramid ratio built from the transversal and cevian sub-triangles.*
